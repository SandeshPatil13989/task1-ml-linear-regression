# House Price Prediction using Linear Regression

## Project Overview
This project is part of the Artificial Intelligence & Machine Learning Task-1.
The goal is to build and evaluate a Linear Regression model using the California Housing Dataset.

## Dataset
- California Housing Dataset (scikit-learn)

## Tools Used
- Python
- Jupyter Notebook
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Model
- Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Files
- `task1_ml_linear_regression.ipynb` – Jupyter Notebook
- `Task1_House_Price_Prediction_Report.pdf` – Project Report
- `house_price_model.pkl` – Saved model (optional)

## Result
The model predicts house prices with reasonable accuracy and demonstrates the complete machine learning workflow.
